## 核心目标
大幅减少 context 工程重量，将每轮 11000-26000 tokens 降至 ~2300 tokens，解决首字延迟和输出速度慢的问题。

## 架构哲学：功能主义定义
- 固定 LLM（不可改权重）+ 涌现式记忆网络（在线生长）= 人类大脑记忆
- LLM = 新皮层，负责推理
- 记忆网络 = 海马体+边缘系统，决定此刻该让底座看到什么

## 五层架构

### LAYER 0: 固定底座（Fixed Base）
外部 LLM API / 本地模型，权重不可改，只负责接收 Prompt → 生成 Token

### LAYER 1: 涌现记忆网络（核心）
- 节点：文本摘要、情绪标签、关键词、时间戳、平台标签、激活值、基线激活、出边连接
- 五条最小规则：节点自治、共现即连接、激活即扩散、竞争即抑制、沉默即遗忘
- 入口匹配：分布式无中央查询，每个节点本地计算
- 巩固：行为投票制（深入同话题+0.15、纠正-0.10、表达依赖+0.20）
- 延迟/离线：合并、分裂、修剪

### LAYER 2: 人格层（基点 + 模式）
- 基点（Base Self）：~150 tokens，常驻，永不被竞争掉
- 情境模式（Mode Node）：竞争 7 槽之一，日常/深夜/工作/技术等

### LAYER 3: 工具与技能层
- 工具：意图门控，只暴露索引（~200 tokens）+ 当前激活工具 schema（~800 tokens）
- 技能：L0 索引常驻（~300 tokens），L1/L2 按需加载

### LAYER 4: 多平台与代理层
- 统一记忆网络，平台标签权重调制（×0.3 抑制）不隔离
- Sub-agent 经历注入：同步并行 + 异步后台
